# 6 aus 49 – Lottosimulator

Eine kleine, responsive Web-App zur Simulation einer 6-aus-49-Ziehung.

## Funktionen

- Auswahl von genau sechs Zahlen zwischen 1 und 49
- Zufällige Tippauswahl
- Zufällige Ziehung von sechs unterschiedlichen Zahlen
- Anzeige der Treffer
- Responsive Darstellung für Desktop und Mobilgeräte

## Start

Öffne `index.html` in einem Browser oder starte einen lokalen Server:

```bash
python3 -m http.server 8080
```

Danach ist die App unter `http://localhost:8080` erreichbar.
